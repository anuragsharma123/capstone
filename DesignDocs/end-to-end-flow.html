Four places it waits for a person

Pick the tools · add a missing connection · approve a risky action · pass admin review. Each is a checkpoint — the run can stop for minutes or for days, survive a server restart, and pick up exactly where it left off.

Three gates that can turn you around

  • connection missing the build won't continue until every tool it picked has a working connection
  • score below the bar Publish stays disabled, and the page tells you which number fell short
  • admin sends it back you get notes, fix the agent, re-submit — the review resumes, it doesn't restart
